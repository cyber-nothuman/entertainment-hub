# Orbit — entertainment hub

A responsive, static entertainment discovery site with search, format and mood filters, a saved list, random picks, and a lightweight recommendation chat.

## Run it

Open `index.html` in a browser, or serve this folder with any static web server. No build step, package installation, account, or API key is required. It can also be hosted as a static site, including GitHub Pages.

## What works

- Search titles, genres, descriptions, and tags.
- Filter the built-in collection by movies, series, games, or music.
- Browse by mood, ask Orbit for suggestions, or get a surprise pick.
- Save favorites in browser local storage and revisit them under **Your list**.
- Open item details with keyboard-accessible controls.
- Responsive layout for mobile and desktop.

Orbit's chat is a small local recommendation helper over the included sample collection, not a generative AI service and not a live catalog. Saved items stay in the current browser. No password gate is included: a password embedded in a static website would not protect private content. If you want real AI responses or secure accounts, those need a server-side provider integration and authentication.
